# Literature Review

## 1. 논문 1: EIS 기반 SOH 추정

- EIS 데이터를 활용하여 배터리 내부 특성을 추출하고 SOH를 예측
- 등가회로 모델(ECM)과 가우시안 프로세스 회귀(GPR) 사용

### 주요 결과
- 다양한 온도 조건에서도 높은 정확도 (RMSE 약 1.77%)
- 배터리 열화가 진행될수록 임피던스 증가 경향 확인

### 한계
- EIS 장비 필요 → 실제 공업사 환경 적용 어려움
- 내부저항 단일 변수로는 정확한 예측 어려움

### 본 연구와의 연결
- 단순 전압/전류 기반 모델보다 **내부 물리 특성 기반 접근이 중요**
- 본 연구에서는 EIS 대신 **공업사 데이터(내부저항, CCA)를 활용하여 내부 특성을 간접 추정**

## 2. 논문 2: 시상수 기반 SOH 추정

- 배터리의 시상수(Time Constant)를 이용하여 SOH 추정
- 전압 응답의 변화율을 이용하여 시상수 계산

### 주요 결과
- 시상수와 SOH 간 명확한 관계 존재
- SOH 추정 오차 2% 이하

### 한계
- 시상수 변화의 물리적 원인 설명 부족

### 본 연구와의 연결
- 시상수는 RC 등가회로 기반 핵심 지표
- 본 연구에서는 내부저항(R)과 CCA(C 관련 변수)를 이용하여
  **시상수와 유사한 Feature를 구성하고 SOH 예측에 활용**

  ## 3. 논문 3: ECM 파라미터 변화 분석

- 배터리 열화에 따른 등가회로 파라미터 변화 분석

### 주요 결과
- 열화 진행 → 직렬 저항 증가
- 커패시턴스 성분 감소

### 본 연구와의 연결
- 내부저항 증가 → 열화 진행 지표
- CCA 감소 → 저장 능력 감소
→ 공업사 데이터만으로도 ECM 파라미터 변화 간접 반영 가능

## 4. 논문 4: EIS 기반 SOH 연구 리뷰

- 다양한 연구에서 Rct, Cdl 등 임피던스 파라미터가 SOH와 높은 상관관계

### 주요 내용
- 기존 BMS는 시간 영역 데이터 중심
- EIS는 주파수 영역에서 더 많은 내부 정보 제공

### 본 연구와의 연결
- 공업사 데이터는 EIS를 직접 측정할 수 없음
- 따라서 내부저항과 CCA를 이용해
  **EIS 기반 정보를 간접적으로 반영하는 모델 설계**

  ## 5. 정리

기존 연구는 EIS 기반으로 배터리 내부 특성을 분석하여 SOH를 예측하지만,
본 연구에서는 공업사에서 측정 가능한 제한된 데이터(내부저항, CCA 등)를 활용하여
RC 등가회로 특성을 간접적으로 반영하고 SOH를 예측하는 모델을 설계한다.
